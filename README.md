# TEMPO · tempo-av.github.io

Website and electronic press kit of TEMPO, audiovisual collective from Milano.

- `index.html`: the DIVE site (WebGL particle field per work, original colour image underneath, audio rising with scroll). `?at=2.5` jumps to a position for previews.
- `t/` stills, `v/` videos, `a/` audio per work.
- `TEMPO_Portfolio_2026.pdf`: portfolio / EPK 2026.
